# Inventory Management System

Учебный проект на JavaScript для управления каталогом товаров и учёта складских остатков.

## О проекте

Программа моделирует работу небольшого склада: хранит информацию о товарах, позволяет добавлять новые позиции, находить товары по ID и изменять их количество на складе.

## Функциональность

- Хранение каталога товаров в массиве объектов.
- Добавление новых товаров с помощью функции `addProduct`.
- Поиск товаров по ID с помощью функции `findProductById`.
- Изменение складских остатков с помощью функции `updateStock`.
- Проверка наличия товара перед изменением его остатка.
- Обработка ситуации, когда товар не найден.

## Используемые технологии

## Ограничения проекта

Это учебная консольная программа. Каталог товаров заранее задан в коде. Добавление и изменение товаров выполняются во время работы программы. Подключение к базе данных и пользовательский интерфейс не реализованы.
